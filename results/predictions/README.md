# Sample Botanical Predictions Archive

This directory records verifiable prediction outputs generated by the serialized Gaussian Naive Bayes classifier (`iris_model.pkl`) across representative specimens from each morphological cluster.

---

## Output Format & Schema

Each entry in [`sample_predictions.json`](sample_predictions.json) includes the feature vector, the ground-truth taxon, the predicted taxon, and the posterior probability distribution:

```json
{
  "index": 0,
  "features": {
    "sepal length (cm)": 5.1,
    "sepal width (cm)": 3.5,
    "petal length (cm)": 1.4,
    "petal width (cm)": 0.2
  },
  "true_class": "setosa",
  "predicted_class": "setosa",
  "probabilities": {
    "setosa": 1.0,
    "versicolor": 0.0,
    "virginica": 0.0
  }
}
```

---

## Verifiability

These predictions can be reproduced dynamically via the REST API endpoint:

```bash
curl -X POST http://127.0.0.1:5001/predict \
  -H "Content-Type: application/json" \
  -d '{"sepal length (cm)": 5.1, "sepal width (cm)": 3.5, "petal length (cm)": 1.4, "petal width (cm)": 0.2}'
```
